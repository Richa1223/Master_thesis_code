# Simulation analysis

This directory contains the TNG50 analysis code used in the Master's
thesis.

The analysis uses TNG50-1 and TNG50-1-Dark at snapshot 99.

The scripts cover:

- TNG50 halo sample selection
- stellar and dark-matter particle loading
- coordinate and unit conversion
- galaxy orientation and projection
- projected stellar and dark-matter map construction
- projected axis-ratio measurements
- radial surface-density and surface-brightness profiles
- intrinsic three-dimensional dark-matter halo shapes
- matched TNG50 / TNG50-Dark halo comparisons
- HSC--TNG comparison products
