# HSC--TNG50 Comparison

This directory contains the scripts used for the direct comparison between the
final HSC observational sample and simulated galaxies from TNG50.

The comparison connects the observed faint stellar-light distributions with
projected stellar and dark-matter structure measured in the simulations.

## Comparison Strategy

Each HSC galaxy is compared with five TNG50 systems selected by proximity in
stellar mass.

For every selected simulated system, three orthogonal projections are used,
providing up to 15 analogue--projection realizations per observed galaxy.

The three projections of a given simulated galaxy are not statistically
independent because they represent different views of the same underlying
physical system.

## Stellar-Mass Selection

The TNG50 comparison systems are selected using proximity in stellar mass.

The comparison uses the five nearest simulated systems in stellar mass for each
observed HSC galaxy.

Two observed galaxies, HSC-332 and HSC-75, lie below the stellar-mass range of
the processed TNG50 comparison sample. For these systems, the nearest available
simulated galaxies are used rather than close stellar-mass matches.

## Photometric Band Matching

The main TNG50 population analysis uses synthetic g-band photometry.

For the direct HSC--TNG comparison, new TNG stellar-light maps are constructed
in the synthetic r band so that the simulated stellar photometry is evaluated
in the same band as the HSC observations.

The r-band stellar magnitudes correspond to Python index 5 of
`GFM_StellarPhotometrics`.

## Surface-Brightness Comparison

Observed HSC r-band surface-brightness profiles are compared with the
corresponding simulated TNG50 r-band stellar-light profiles.

The comparison is carried out as a function of projected physical radius.

The HSC measurements are restricted to the galaxy-specific radial range over
which the observed profile remains above its adopted empirical
surface-brightness limit.

## Projected Shape Comparison

The comparison also examines radial projected axis-ratio profiles.

For the HSC galaxies, the radial stellar-light axis ratio is measured directly
from the observed r-band images.

For the simulations, projected stellar-light and dark-matter axis-ratio
profiles are measured in the same viewing direction.

The purpose is to compare:

- observed stellar-light shape
- simulated stellar-light shape
- simulated dark-matter shape

as functions of projected physical radius.

## Interpretation

The comparison is designed to test whether galaxies with similar stellar mass
show similar faint stellar-light structure and whether the projected stellar
distribution provides useful information about the surrounding dark-matter
halo.

The comparison should not be interpreted as a one-to-one reconstruction of
dark-matter halo shape from stellar light.

Scatter can arise from differences in:

- halo mass
- morphology
- viewing direction
- merger and accretion history
- environment
- stellar-mass definition
- observational systematics

## Main Scripts

### `Select_5_mass_matches.py`

Selects the five TNG50 galaxies closest in stellar mass to each HSC galaxy.

### `make_r_band_maps.py`

Constructs the TNG50 synthetic r-band stellar-light maps used for the direct
comparison with HSC.

### `SB_comparison.py`

Compares the observed HSC and simulated TNG50 radial surface-brightness
profiles.

### `final_shape_comparison.py`

Produces the main HSC--TNG projected stellar-shape comparison.

### `light_q_dm_comparison.py`

Compares projected stellar-light and dark-matter axis-ratio profiles for the
selected simulated systems.

## Connection to Other Directories

The scripts in this directory use products generated by both:

- `Observations/`
- `simulation/`

The observational directory provides the final HSC profiles and galaxy
properties.

The simulation directory provides the projected TNG50 stellar and dark-matter
measurements.

This directory combines these products into the final HSC--TNG comparison.

## Notes on Reproducibility

Some scripts depend on derived profile tables and map products created by the
observational and simulation pipelines.

Local file paths may therefore need to be updated before running the scripts on
another system.

The repository does not distribute the original HSC or TNG50 datasets.
